# Giftology — The Perfect Gift Finder

An interactive, lavender-themed personalized gift discovery platform built with React, Vite, and Tailwind CSS.

## Features
- **Email & Phone OTP Gate:** Interactive authentication flow with instant demo OTP autofill (`123456`).
- **Memory-Driven Recommendation Engine:** Tailored gift matching across 11 relationships, favorite memories, interests, color palettes, and budgets (`₹200 – ₹10,000`).
- **Indian E-Commerce Price Comparison:** Side-by-side price and delivery comparisons across Amazon, Flipkart, Ajio, Myntra, and Meesho.
- **Interactive 3D Keepsake & Message Studio:** Drag-to-rotate 3D gift previewer with customizable gift wrap colors and live occasion card composer.
- **Wish List & Occasion Reminders:** Save favorite items, share wish lists, and track upcoming birthdays or anniversaries.
